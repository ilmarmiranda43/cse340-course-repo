# CSE 340 Service Network — Week 01

Starter project for the BYU-Idaho CSE 340 Week 01 assignment.

## IMPORTANT: replace the images
The PNGs under `public/images` are original **temporary placeholders** so the site renders immediately. For the course assignment, replace them with the four logos provided in the W01 Express and Routing learning activity, preserving file names: https://byui-cse.github.io/cse340-ww-course-v2/week01/prepare-routing.html

## Run locally
1. `npm install`
2. `npm run dev`
3. Visit http://127.0.0.1:3000

## Publish
Commit the project to your public GitHub course repository. Never commit `.env` (excluded via `.gitignore`). On Render, create a Node web service, build command `npm install`, start command `npm start`, add environment variable `NODE_ENV=production`.

## Check
Test `/`, `/organizations`, `/projects`, `/categories`, all nav links, images, shared header and footer, dynamic page titles, desktop/mobile CSS, and live Render URL. Submit GitHub and Render links in Canvas.
